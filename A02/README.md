# A02 - Working with a Text File in Python

This assignment contains a Python script that processes a text file.

The script counts:

- the number of paragraphs in the text
- the number of spaces immediately following a dot character

## Clone the repository

Clone the repository from GitHub:

```bash
git clone https://github.com/vojtech-jansa/ci2.git
```

Move to the assignment directory:

```bash
cd ci2/A02
```

## Run the script

Run the script with the provided `test.txt` file:

```bash
python texter.py test.txt
```

On Windows, if the `python` command is not available, use:

```bash
py texter.py test.txt
```

If no file name is provided:

```bash
python texter.py
```

the script prints instructions on how to use it.

## Test result

For the provided `test.txt` file, the output is:

```text
Number of paragraphs: 5
Spaces after a dot: 43
```
